Настройки и синхронизация

GitHub PAT хранится только в localStorage вашего браузера

Создайте Personal Access Token с правом contents: write (classic: repo). Токен не попадает в репозиторий — только в память браузера на этом устройстве. В GitHub уходит только зашифрованный data/state.json.

Смена PIN / пароля

После смены обновите GitHub Secret APP_PASSWORD — иначе бот не сможет читать данные.

Как это работает 24/7

Сайт на GitHub Pages. Данные шифруются в браузере (AES-GCM) вашим PIN и только потом записываются в data/state.json. GitHub Actions расшифровывает файл секретом APP_PASSWORD и шлёт пуш через ntfy.sh — даже когда ноутбук выключен.
